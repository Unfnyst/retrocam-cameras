# RetroCam: shared cameras

Cameras deployed from the RetroCam app (custom camera → Menu → **DEPLOY**).
Every phone running RetroCam 1.6 or newer reads `cameras.json` when the app opens and adds new
cameras to **My cameras**.

Entries are plain camera settings (body, film, lens, frame, ratio, grain, light leaks, date
stamp, name, colour). The app checks every value and keeps it within its normal limits.
